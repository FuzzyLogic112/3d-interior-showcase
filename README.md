# 🏠 3D 室内设计展示 · 现代简约两室一厅

为室内设计师打造的 3D 可交互方案演示页。打开浏览器，就能带客户"走进"一套 89㎡ 的现代简约两室一厅：拖动家具实时改布局、换配色、切灯光、点家具看参数，一次讲清整套方案。

🔗 **在线体验：** https://fuzzylogic112.github.io/3d-interior-showcase/

## ✨ 功能亮点

- 🏡 **完整户型建模**：玄关 / 客厅 / 餐厅 / 厨房 / 主卧 / 次卧 / 卫生间 / 阳台，全部按真实尺寸搭建（10.8m × 8.2m，层高 2.8m）
- 🎥 **三种视角**：3D 漫游（旋转 / 缩放 / 平移）/ 平面俯视（带房间名称与开间×进深标注）/ 第一人称行走（WASD + 鼠标拖拽）
- 🖱️ **布置模式**：直接拖动家具实时调整摆位，按 R 旋转 45°，一键重置布局——客户说"沙发换个方向看看"时当场就能拖
- 🎨 **一键换肤**：「原木暖阳」「云雾灰」「奶油白」三套材质主题，0.6s 平滑过渡
- 💡 **日夜灯光**：白天暖阳斜射 / 夜晚筒灯、灯带、落地灯点亮
- 🪑 **家具点选**：点击任意家具，弹出名称、尺寸、材质与设计说明
- 🧭 **自动导览**：玄关 → 阳台一键巡游，每站停留 4 秒弹出设计亮点，可随时中断

## 🖥️ 使用方式

- **在线访问**上面的链接，手机、平板、电脑都能看
- **本地打开**：直接用 Chrome / Edge 打开 `index.html` 即可，无需起服务器
- **投屏演示**：在线访问需要网络（Three.js 从 CDN 加载）；建议提前打开一次完成缓存，现场演示更流畅
- **纯离线版**：本仓库是在线版。如需无网络也能打开的纯离线单文件版，可在 Muse 的「3D 室内设计展示」Artifact 中导出

## 🛠️ 改成自己的真实项目

本页为模板化设计：修改源码中的 `ROOMS`（房间划分）、`WALLS`（墙体）与家具清单，即可替换为真实项目的户型与部品清单。

## 技术栈

Three.js r147（CDN 加载，jsdelivr / unpkg / cdnjs 自动 fallback）· 原生 HTML / CSS / JS · 零构建、零依赖安装
